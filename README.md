# Sauce Labs Sample Application (Swag Store)

Учебный проект: тестирование веб-приложения интернет-магазина Sauce Demo.
Приложение — демо-магазин Sauce Labs, используется для практики E2E-тестирования на Playwright.

## Стек

- **Frontend:** React + Vite
- **Тесты:** Playwright (TypeScript)
- **Page Object Model:** да (`pageObject/pages`)
- **Node.js:** >= 24.9.0

## Запуск приложения

```bash
npm install
npm run start
```

Приложение открывается на [http://localhost:3000/](http://localhost:3000/).

## Запуск тестов

```bash
npx playwright test
```

Отчёт:

```bash
npx playwright show-report
```

| --- | -------------------------------------------------------------------------------------- | ---------- |

| ID    | Описание                                         | Шаги воспроизведения                                                                                                       | Ожидаемый результат                         | Фактический результат               | Severity | Статус |
| ----- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | ----------------------------------- | -------- | ------ |
| BUG-1 | Поле Zip принимает буквы                         | 1. Войти валидным пользователем 2. Добавить товар 3. Перейти к оформлению 4. В поле Zip ввести `fsadsa` 5. Нажать Continue | Валидация не пропускает, остаёмся на шаге 1 | Заказ оформляется, переход на шаг 2 | High     | Open   |
| BUG-2 | Можно начать оформление заказа с пустой корзиной | 1. Войти валидным пользователем 2. Открыть корзину (пустую) 3. Нажать Checkout 4. Заполнить форму 5. Нажать Continue       | Ошибка / блокировка оформления              | Переход на шаг 2, заказ оформляется | High     | Open   |
